# Nicole Blog — design brief

## Direction

A personal portfolio that feels editorial and immersive: broad sections, confident typography, clear labels, and strong contrast. The Chemistry Brand references inform the rhythm and visual restraint; the result should remain Nicole's own site.

## Visual system

| Role | Color |
| --- | --- |
| Statement | `#FE2BBE` electric fuchsia |
| Main text / dark section | `#111111` near black |
| Base | `#FFFFFF` white |
| Quiet surface | `#F2F2F2` light gray |
| Optional soft surface | `#F7E9EF` pale blush |

Square corners throughout. Minimal motion: only small hover color changes and native scrolling, with reduced-motion support. No profile photo in the initial version.

## Site structure

1. **Home** — oversized typographic introduction, selected work, research theme, writing preview.
2. **Experience** — work at Millennium Management, Meet Magellan, and Deloitte Consulting.
3. **Research + projects** — responsible AI research and selected technical projects, beginning with Pinlog from HackCMU 2026.
4. **Writing** — empty until Nicole publishes an approved first post.

## Content voice

Direct, curious, specific, and readable to both technical and nontechnical visitors. Explain what a project did and why it mattered before listing tools. Avoid inflated claims or detail that has not been cleared for public use.

## Visual references

The source images remain in the project root (`~/Documents/Nicole_Blog`). They are design references, not publishable site assets. The third-party screenshots should stay out of Git and the deployed site.
